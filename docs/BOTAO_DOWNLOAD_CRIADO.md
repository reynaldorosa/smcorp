## 📥 **COMO OBTER O CÓDIGO-FONTE COMPLETO**

### **OPÇÃO 1: Export do Figma Make (RECOMENDADO)**

1. No Figma Make, procure:
   - Botão **"Download"** ou **"Export"** (canto superior)
   - Menu **☰** → **"Export Project"**
   - Atalho: `Ctrl+Shift+E` (Win) ou `Cmd+Shift+E` (Mac)

2. Salve o arquivo `.zip` na sua máquina

3. Descompacte

4. **Pronto!** Você terá TODOS os 95 arquivos .tsx/.ts

### **OPÇÃO 2: Via GitHub**

Se você já fez push para o GitHub:

```bash
git clone https://github.com/SEU-USUARIO/smcorp-platform.git
cd smcorp-platform
npm install
npm run dev
```

### **OPÇÃO 3: Copiar Manualmente**

Se preferir, copie os arquivos do Figma Make para sua máquina:

1. No Figma Make, abra cada arquivo
2. Copie o conteúdo (`Ctrl+A` → `Ctrl+C`)
3. Cole em um arquivo local
4. Repita para todos os arquivos necessários

## 🎯 **FLUXO RECOMENDADO**

## 📞 **PRECISA DE AJUDA?**

Se o botão não aparecer:
1. Recarregue a página (`F5`)
2. Limpe o cache (`Ctrl+Shift+R` ou `Cmd+Shift+R`)
3. Verifique se está na aba "Backup" do Módulo 00

Se o download não funcionar:
1. Verifique as permissões do navegador para downloads
2. Desabilite bloqueadores de pop-up temporariamente
3. Tente em outro navegador
