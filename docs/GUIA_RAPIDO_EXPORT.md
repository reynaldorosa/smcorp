# 🎯 GUIA RÁPIDO: EXPORT PROJECT

## 🚀 3 FORMAS DE EXPORTAR

---

## 1️⃣ BOTÃO NO TOPO (MAIS FÁCIL)

```
┌─────────────────────────────────────────────────────┐
│  Figma Make - Seu Projeto            [📥 Export]   │ ← CLIQUE AQUI
│                                              ↑↑↑    │
└─────────────────────────────────────────────────────┘
```

**Procure:**
- Canto **superior direito**
- Botão **"Export"** ou ícone **📥**
- Pode estar escrito "Download" ou "Export Project"

---

## 2️⃣ MENU HAMBURGER (☰)

```
┌──────────────────────┐
│ ☰  Figma Make        │ ← CLIQUE AQUI
└──────────────────────┘
         ↓
┌──────────────────────┐
│  File                │
│  Edit                │
│  ───────────         │
│  📥 Export Project   │ ← CLIQUE AQUI
│  Settings            │
│  Help                │
└──────────────────────┘
```

**Procure:**
- **☰** (três linhas) no canto superior esquerdo
- Opção **"Export Project"** no menu

---

## 3️⃣ ATALHO DE TECLADO (MAIS RÁPIDO)

### **Windows:**
```
Ctrl + Shift + E
```

### **Mac:**
```
Cmd ⌘ + Shift + E
```

**Pressione as 3 teclas ao mesmo tempo!**

---

## 📥 O QUE FAZER DEPOIS

### **Quando a janela abrir:**

```
┌───────────────────────────────────┐
│  📥 Export Project                │
├───────────────────────────────────┤
│                                   │
│  Export Format:                   │
│  ⦿ Complete Project (ZIP)  ← MARQUE│
│  ○ Source Code Only               │
│                                   │
│  [Cancel]      [Export]           │
│                     ↑↑↑           │
│                  CLIQUE AQUI       │
└───────────────────────────────────┘
```

1. **Marque:** "Complete Project (ZIP)"
2. **Clique:** "Export" ou "Download"
3. **Aguarde:** 10-30 segundos
4. **Pronto!** Arquivo ZIP baixado

## 🔧 INSTALANDO O PROJETO

### **Após baixar o ZIP:**

```bash
# 1. Descompactar o arquivo
# (clique duas vezes no ZIP ou use extrator)

# 2. Abrir terminal na pasta
cd smcorp-platform

# 3. Instalar dependências
npm install

# 4. Executar projeto
npm run dev

# 5. Abrir navegador
# http://localhost:5173
```
