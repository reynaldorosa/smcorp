## 🔍 IDENTIFICADORES HTML

### **Seletores CSS para encontrar o botão:**

```css
/* Aba Backup */
[value="backup"]

/* Card do Download */
.bg-gradient-to-r.from-blue-50.to-indigo-50

/* Botão */
button:has(svg.lucide-download):contains("Baixar Documentação")
```

### **Console JavaScript:**

```javascript
// Encontrar o botão
const botao = Array.from(document.querySelectorAll('button'))
  .find(b => b.textContent.includes('Baixar Documentação Completa'));

// Destacar o botão
botao.style.border = '5px solid red';
botao.style.animation = 'pulse 1s infinite';

// Clicar programaticamente
botao.click();
```

## 🎯 TROUBLESHOOTING VISUAL

### **Problema 1: Aba "Backup" não aparece**
```
ANTES:     grid-cols-8 (errado)
DEPOIS:    grid-cols-9 (correto) ✅
```

### **Problema 2: Card não aparece**
```
Solução: Role a página para baixo
O card está abaixo do "Backup de Dados"
```

### **Problema 3: Botão cortado**
```
Solução: Maximize a janela ou reduza zoom (90%)
```
